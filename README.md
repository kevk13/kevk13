This repository features AI-powered GitHub Actions workflows:

- **AI Issue Responder** - Automatically labels and responds to new issues using AI
- **AI PR Reviewer** - Reviews pull request diffs and provides AI-generated feedback
- **AI Profile Updater** - Keeps this profile README fresh with recent GitHub activity

#### Setup

To enable AI-powered responses, add an `OPENAI_API_KEY` secret to this repository under **Settings > Secrets and variables > Actions**. Without the key, the workflows still function with basic automation (auto-labeling, acknowledgment comments).
